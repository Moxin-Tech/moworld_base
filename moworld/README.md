# MoWorld Pretraining

This directory contains the MindSpeed-MM-based implementation for MoWorld expert pretraining and data preparation.

- [Quick Start](../README.md#installation)
- [Environment, checkpoint preparation, and training](../USAGE.md)
- [Pretraining launchers and configurations](examples/moworld/)

The internal Python package remains `mindspeed_mm`. Shared model registries and checkpoint utilities are retained for training compatibility. MoWorld inference launchers and dedicated inference modules are not included.
